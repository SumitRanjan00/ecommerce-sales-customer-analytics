# E-Commerce Sales and Customer Analytics Using Python and AI

## Dataset
Kaggle: E-commerce Sales Transactions Dataset
https://www.kaggle.com/datasets/miadul/e-commerce-sales-transactions-dataset

## Problem
Analyze raw e-commerce transactions to understand sales, customers, categories, regions, returns and profitability, and use K-Means clustering for customer segmentation.

## Objectives
- Clean and validate the data
- Analyze sales and category performance
- Study customer, region and payment behavior
- Analyze discounts, delivery, returns and profitability
- Segment customers with RFM-style features and K-Means
- Generate business insights

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter

## Dataset Snapshot
- Transactions: 34,500
- Unique customers: 7,903
- Total sales: 5,865,293.05
- Average order value: 170.01
- Return rate: 5.52%

## Run
Install: `pip install -r requirements.txt`
Then open `SumitRanjan_EcommerceSalesAnalytics.ipynb` in Jupyter and run all cells.

## AI Component
Customer Recency, Frequency and Monetary features are standardized and clustered using K-Means with 4 clusters.
